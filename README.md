# Simple Text & ASCII Art Displayer

โปรเจกต์ขนาดเล็กสำหรับทดสอบการแสดงผลข้อความ (String) และการจัดการช่องว่าง (Whitespace) ในภาษา Python โดยมีการใช้ Multi-line string เพื่อสร้างงานศิลปะจากตัวอักษร

## การทำงานของโปรแกรม
1. พิมพ์คำว่า `Hello world` ออกทางหน้าจอ
2. พิมพ์กลุ่มข้อความที่มีการจัดวางรูปแบบพิเศษ (ASCII Art) โดยใช้ตัวอักษรจีน "核心" (Héxīn) ซึ่งแปลว่า "แกนกลาง" หรือ "Core"

## วิธีการใช้งาน
รันไฟล์ด้วยคำสั่ง Python พื้นฐาน:
```bash
python main.py

---

### 🐍 main.py

```python
# แสดงข้อความต้อนรับพื้นฐาน
print('Hello world')

# มีการจัดวางตัวอักษรจีนเพื่อสร้างรูปทรงศิลปะ
text = '''
HI 009999  000245

                核心核心核心核心
                核心        核心核心
                核心  核心核心核心核心
                核心  核心核心核心
核心            核心核心核心
核心核心        核心核心核心核心
  核心核心核心核心核心核心核心
    核心核心核心核心核心核心
      核心核心核心核心核心           核心
          核心    核心             核心  核心
          核心    核心          核心  核心  核心
          核心核心  核心核心       核心  核心  核心
______________________________     核心  核心     _______

'''

# แสดงผลรูปภาพตัวอักษรออกทาง Console
print(text)
