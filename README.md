# 🌊 Nautical ASCII Art System

โปรแกรมแสดงผลภาพศิลปะ ASCII ในธีมท้องทะเล พร้อมระบบสีสันผ่าน Terminal และเมนูควบคุมการทำงาน

## ✨ คุณสมบัติ (Features)
*   **ASCII Art Display:** แสดงภาพเรือใบ (Ship) และประภาคาร (Lighthouse) ที่จัดวางอย่างสวยงาม
*   **Terminal Colors:** รองรับการแสดงผลแบบมีสีสันด้วย ANSI Escape Sequences
*   **Simple Menu:** มีระบบเมนูโต้ตอบผ่าน Command Line (CMD)
*   **Clean Interface:** มีระบบล้างหน้าจออัตโนมัติเพื่อให้ดูข้อมูลได้สบายตา

## 🚀 วิธีการใช้งาน (How to Use)
1.  ตรวจสอบว่าเครื่องของคุณติดตั้ง **Python 3.x** แล้ว
2.  ดาวน์โหลดหรือคัดลอกโค้ดไฟล์ `.py` ไว้ในเครื่อง
3.  เปิด Terminal หรือ Command Prompt แล้วไปยังโฟลเดอร์ที่เก็บไฟล์
4.  รันโปรแกรมด้วยคำสั่ง:
    ```bash
    python your_filename.py
